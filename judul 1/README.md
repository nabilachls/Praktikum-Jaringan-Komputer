# Judul 1 Praktikum Jaringan Komputer - Basic Network Configuration

## 🖼️ Topologi Jaringan

Berikut adalah diagram skema topologi jaringan yang telah dibuat pada Cisco Packet Tracer:

![Topologi Jaringan Judul 1](./Screenshot%202026-10-03%20191820.png)

### Komponen Perangkat:
- **PC0:** Generic PC (PC-PT) - Client pada subnet LAN 1
- **Switch0:** Cisco Catalyst 2960-24TT - Menghubungkan client PC0 ke Router0
- **Router0:** Cisco 2911 Router - Gateway routing antar-subnet
- **PC1:** Generic PC (PC-PT) - Client pada subnet LAN 2 (terhubung langsung ke Router0)
