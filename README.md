## 💻 Cara Menjalankan Berkas Simulasi
1. Clone repositori:
   ```bash
   git clone https://github.com/nabilachls/Praktikum-Jaringan-Komputer.git
   ```
2. Buka software **Cisco Packet Tracer**.
3. Buka file `.pkt` dari folder judul praktikum yang ingin diuji (misal: `judul 1/judul1pjk.pkt`).
